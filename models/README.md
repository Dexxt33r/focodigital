# 3D menu assets

- burger.glb: web / Android model used by model-viewer.
- burger.usdz: Apple Quick Look model used by Safari and supported iOS browsers.
- Source: https://grab3d.com/models/food/burger/
- License: CC0 1.0 (public domain dedication; commercial use and modification allowed, no attribution required according to the source page).
- Approximate model dimensions: 0.134 x 0.132 x 0.103 m. The AR viewer uses fixed scale based on the asset; actual restaurant food dimensions will vary.

The 3D model is a stylized PBR asset, not a photogrammetric scan of a real menu item.
